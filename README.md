# Сезонный календарь · Москва

Календарь сезонности фруктов, ягод и овощей для московского покупателя. На главном экране показан текущий месяц по московскому времени.

Найдите продукт и выберите страну или российский регион с ценника. Карточка показывает один из статусов: пик сезона, в сезоне, граница сезона, хранение, теплица, круглый год или сезон не установлен. Несезон обозначен отдельно.

Внутри карточек доступны пояснения, календарь на год и источники. Статусы описывают сезонность, а не гарантируют вкус конкретного плода. Дата проверки базы: 20 сентября 2026 года. Строки без достаточных подтверждений обозначены явно.

## Возможности

- Поиск продукта, страны и региона.
- Список на сегодня и таблица по месяцам.
- Россия целиком или отдельное российское происхождение.
- Личное избранное и светлая / тёмная тема.
- Адаптация для телефона.

Избранное хранится только в браузере пользователя и не синхронизируется между устройствами. Регистрация для просмотра календаря не нужна. Дата меняется автоматически; база источников обновляется при выпуске новой версии сайта.

## Размещение

Это статический сайт без зависимостей и сборки. GitHub Pages публикует `index.html` из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll.

Для обновления календаря замените `index.html` новой проверенной версией и сохраните изменения в `main`.

Сайт можно добавить на главный экран телефона через меню браузера. Открытие без интернета не гарантируется.
