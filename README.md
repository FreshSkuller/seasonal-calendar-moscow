# Сезонный календарь · Москва

[Открыть сайт](https://freshskuller.github.io/seasonal-calendar-moscow/)

Календарь покупателя: сезонность по московской дате и происхождению, советы о выборе и спелости, источники, поиск и избранное. Репозиторий содержит весь исходный код, данные и готовый самостоятельный `index.html` для GitHub Pages.

## Запуск

Нужен Node.js 22 или новее с npm. В папке репозитория:

```sh
npm ci
npm run build
npm test
npm start
```

Откройте http://127.0.0.1:8765. После правки исходников повторите сборку и обновите страницу. Сервер останавливается Ctrl+C. Готовый `index.html` можно открыть и без сервера; для просмотра сайта Node.js не нужен.

## Где что менять

| Задача                                  | Место                                                  |
| --------------------------------------- | ------------------------------------------------------ |
| Надписи, кнопки, подсказки              | `content/ru.json`                                      |
| Продукты и варианты                     | `data/products/`, `data/variants/`                     |
| Сезонность, советы и основания          | `data/seasons/`, `data/advice/`, `data/evidence/`      |
| Названия и объяснения статусов          | `data/statuses.json`                                   |
| Источники и ограничения их применимости | `data/sources.json`                                    |
| Дата проверки и методология базы        | `data/metadata.json`                                   |
| Разметка разделов                       | `src/templates/partials/`                              |
| Внешний вид                             | `src/styles/`                                          |
| Карточка товара и подробности           | `src/components/product-card.js`, `product-details.js` |
| Поведение экранов                       | `src/views/`                                           |
| Поиск, фильтрация и сортировка          | `src/domain/`                                          |
| Происхождения и категории               | `data/taxonomy/`                                       |
| Модели экранов и состояние              | `src/application/`, `src/state/`                       |

## Проверки и публикация

```sh
npm run format
npm run build
npm test
npm run format:check
```

Браузерные проверки запускаются отдельно, на компьютерной и мобильной ширине:

```sh
npx playwright install chromium
npm run test:browser
```

Можно использовать установленный Chrome. В PowerShell перед запуском тестов выполните `$env:PLAYWRIGHT_CHANNEL='chrome'`.

Перед публикацией просмотрите `git diff`, добавьте нужные изменения в GitHub Desktop и создайте коммит. В коммит должны попасть исходники и пересобранный `index.html`. После push GitHub Pages публикует корень ветки `main`. Зависимости сборки находятся в `package-lock.json`; папка `node_modules` в Git не попадает.

Тесты проверяют ссылки между данными, сборку, фильтры, московскую дату, безопасный вывод текста и пользовательские сценарии. Они не доказывают достоверность сезонности: для изменения месяцев нужны источники. Дата проверки сведений не обновляется при сборке кода.
