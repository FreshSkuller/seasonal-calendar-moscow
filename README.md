# Сезонный календарь · Москва

[Открыть календарь](https://freshskuller.github.io/seasonal-calendar-moscow/)

Мобильный календарь сезонности фруктов, овощей и ягод по месяцу и происхождению. Вкладка «Сегодня» использует московскую дату. Есть поиск, фильтры стран и регионов, избранное, годовая таблица и источники. Избранное хранится в браузере конкретного устройства.

Репозиторий содержит **полный исходный проект** и готовый `index.html` для GitHub Pages. Для сборки не нужны файлы из переписки, платные сервисы, ключи или сторонние библиотеки.

## Начать работу

Установите Node.js версии 20 или новее (вместе с npm), затем:

```sh
git clone https://github.com/FreshSkuller/seasonal-calendar-moscow.git
cd seasonal-calendar-moscow
npm run build
npm test
npm start
```

Откройте http://127.0.0.1:8765. Остановка сервера — Ctrl+C. `npm install` не требуется: внешних зависимостей нет. После изменения исходников повторите сборку и обновите страницу.

Готовый `index.html` также можно открыть прямо в браузере, без сборки и сервера.

## Где что менять

| Файл | Содержимое |
|---|---|
| `data/calendar.json` | Продукты, происхождение, месяцы, пояснения и источники |
| `src/template.html` | Разметка страницы, подписи и разделы |
| `src/styles.css` | Оформление и адаптация под телефон |
| `src/calendar.js` | Годовая таблица, поиск, география, карточка подробностей |
| `src/today.js` | Вкладка «Сегодня», московская дата и избранное |
| `scripts/build.cjs` | Проверка данных и сборка самостоятельного HTML |
| `scripts/serve.cjs` | Локальный просмотр сайта |
| `tests/calendar.test.cjs` | Проверки данных, сборки и географии |
| `index.html` | Готовый сайт; обновляется командой сборки |

Правьте исходники, затем пересобирайте `index.html`. Изменения только в готовом HTML будут перезаписаны следующей сборкой. Маркеры `@@…@@` в шаблоне нужны сборщику.

## Как менять сезонность

В `data/calendar.json` каждая запись в `rows` описывает один продукт и одно происхождение. `months` содержит ровно 12 статусов: от января до декабря.

| Код | Значение |
|---|---|
| `p` | Пик сезона |
| `g` | Хороший сезон |
| `b` | Граница сезона |
| `h` | Хранение |
| `t` | Теплица |
| `n` | Не сезон свежего урожая |
| `u` | Сезон пока не установлен |
| `a` | Круглый год |

Сохраняйте существующий `id`: он используется в избранном. Для новой строки задавайте новый уникальный ID. В `sources` строки указывайте ключи источников из общего раздела `sources`. У источника сохраняйте URL, дату, дату проверки, область применимости (`scope`) и ограничения (`limit`). У строки поясняйте условия сезона в `note`, уверенность в `confidence`, поставки в `supply`.

После проверки обновляйте дату `checked` базы и соответствующих источников. Дата не обновляется автоматически при сборке: сборка не означает повторную проверку сведений.

Поставки и наличие товара сами по себе не доказывают пик вкуса. Подтверждённое завершение сезона позволяет поставить `n` за пределами установленного периода; отсутствие сведений само по себе не превращает `u` в `n`. Хранение, теплицы, другие регионы и сорта оцениваются отдельно. Сборка проверяет структуру данных, но достоверность сезонных сведений требует проверки источников человеком.

Россия объединена общим фильтром и разделяется по происхождению внутри карточек. При добавлении новой зарубежной страны дополните `REGION_COUNTRIES` в `src/calendar.js`. Новые происхождения вида `Россия · Сочи` автоматически попадут в российскую группу.

## Как обновить сайт через Git

```sh
npm run build
npm test
git add data src scripts tests package.json README.md index.html .nojekyll .gitignore .gitattributes
git commit -m "Update seasonal calendar"
git push origin main
```

Просмотрите изменения перед коммитом. GitHub Pages публикует корень ветки `main`; поэтому в коммит нужно включать и исходники, и пересобранный `index.html`. Обновление сайта может занять несколько минут. Автоматическая сборка исходников на GitHub не настроена.

Текущий адрес сайта: https://freshskuller.github.io/seasonal-calendar-moscow/. Для работы GitHub Pages на тарифе GitHub Free репозиторий остаётся публичным.
